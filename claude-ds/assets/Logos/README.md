# Logos

Logo horizontal (mark + wordmark "MaulanaHRP / Tech Solution") dan badge bulat. Wordmark sudah berupa outline (path) Montserrat, jadi tidak butuh font terpasang.

- `maulanahrp-horizontal-color.svg`: **default**. Mark bergradasi cyan → navy, teks navy #1C366B. Untuk latar putih, `mh-color-neutral-50`, atau cyan muda.
- `maulanahrp-horizontal-white.svg`: tinta putih #FFFFFF. Untuk latar `mh-color-navy-800`/`900`, gradasi brand, atau foto gelap.
- `maulanahrp-horizontal-navy.svg`: satu tinta navy #1C366B. Untuk cetak satu warna dan stempel.
- `maulanahrp-horizontal-black.svg`: satu tinta #0C1A38. Untuk fotokopi, fax, dan cetak hitam-putih.
- `maulanahrp-badge-color.svg`: badge bersih (tiga cincin navy + mark + wordmark). Untuk stiker, cover, sertifikat, dan avatar media sosial.
- `maulanahrp-badge-white.svg`: badge bertinta putih untuk latar gelap.
- `maulanahrp-badge.png`: logo asli (raster 878px, bertekstur grunge). Hanya untuk arsip; jangan dipakai di bawah 200px atau untuk cetak besar.
- `maulanahrp-horizontal-color.png`: PNG 1200px untuk Word, PowerPoint, dan email signature.

Area bebas di semua sisi minimal setinggi node bulat pada mark. Lebar minimum horizontal: 120px / 30mm.

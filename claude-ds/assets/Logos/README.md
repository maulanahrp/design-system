# Logos

Badge bulat (logo resmi) dan lockup horizontal. Semua file adalah vektorisasi langsung dari logo asli: bentuk mark dan wordmark tidak digambar ulang, warna disampel dari logo. Tidak butuh font terpasang.

- `maulanahrp-horizontal-color.svg`: **default untuk ruang melebar**. Mark asli bergradasi cyan → biru, "MaulanaHRP" navy #1D3668, "Tech Solution" navy gelap #1C2A45. Untuk latar putih, `mh-color-neutral-50`, atau cyan muda.
- `maulanahrp-horizontal-white.svg`: tinta putih #FFFFFF. Untuk latar `mh-color-navy-800`/`900`, gradasi brand, atau foto gelap.
- `maulanahrp-horizontal-navy.svg`: satu tinta navy #1D3668. Untuk cetak satu warna dan stempel.
- `maulanahrp-horizontal-black.svg`: satu tinta #0C1A38. Untuk fotokopi, fax, dan cetak hitam-putih.
- `maulanahrp-badge-color.svg`: **logo resmi**, persis logo asli tanpa bintik tekstur (tiga cincin navy + mark + wordmark). Untuk stiker, cover, sertifikat, dan avatar media sosial.
- `maulanahrp-badge-white.svg`: badge satu tinta putih tanpa piringan, untuk latar gelap.
- `maulanahrp-badge.png`: logo asli (raster 878px, bertekstur). Hanya arsip dan sumber vektorisasi.
- `maulanahrp-horizontal-color.png`: PNG 1200px untuk Word, PowerPoint, dan email signature.

Area bebas di semua sisi minimal setinggi node bulat pada mark. Lebar minimum horizontal: 180px / 45mm. Diameter minimum badge: 96px / 25mm.

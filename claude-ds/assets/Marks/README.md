# Marks

Mark gelombang (dua node terhubung oleh gelombang) tanpa wordmark, serta ikon aplikasi. Mark SVG adalah interpretasi vektor dari logo raster asli.

- `maulanahrp-mark-color.svg`: gradasi cyan #68C0D2 → navy #274B91, node #3B6CA7. Untuk avatar, loading, dan ikon fitur di latar terang.
- `maulanahrp-mark-navy.svg`: satu tinta navy #1C366B. Untuk watermark dokumen (opacity 5%).
- `maulanahrp-mark-white.svg`: satu tinta putih. Untuk latar navy/gelap.
- `maulanahrp-mark-black.svg`: satu tinta #0C1A38. Untuk cetak hitam-putih.
- `maulanahrp-app-icon.svg`: mark putih di kotak navy #1C366B (radius 112/512). Untuk favicon, ikon aplikasi, dan PWA.
- `icon-512.png`: app icon PNG 512px.

Lebar minimum mark: 24px / 8mm.

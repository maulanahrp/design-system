# Marks

Mark gelombang (dua node terhubung oleh gelombang) tanpa wordmark, serta ikon aplikasi. Mark diambil langsung dari logo asli (vektorisasi), bukan digambar ulang.

- `maulanahrp-mark-color.svg`: warna asli logo: gelombang 2 pita bergradasi cyan → biru, konektor kiri biru tua, konektor kanan cyan. Untuk avatar, loading, dan ikon fitur di latar terang.
- `maulanahrp-mark-navy.svg`: satu tinta navy #1D3668. Untuk watermark dokumen (opacity 5%).
- `maulanahrp-mark-white.svg`: satu tinta putih. Untuk latar navy/gelap.
- `maulanahrp-mark-black.svg`: satu tinta #0C1A38. Untuk cetak hitam-putih.
- `maulanahrp-app-icon.svg`: mark putih di kotak navy #1D3668 (radius 112/512). Untuk favicon, ikon aplikasi, dan PWA.
- `icon-512.png`: app icon PNG 512px.

Lebar minimum mark: 24px / 8mm.

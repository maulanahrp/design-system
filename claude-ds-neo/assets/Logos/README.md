# Logos

Logo MaulanaHRP yang sama dengan gaya utama. Semua file adalah vektorisasi langsung dari logo asli; jangan menggambar ulang atau mengetik ulang wordmark.

- `maulanahrp-horizontal-navy.svg`: tinta navy #1D3668. **Default di Neubrutalism** karena terbaca di atas semua blok terang (paper, sky, cyan, sun, mint).
- `maulanahrp-horizontal-color.svg`: mark bergradasi + teks navy. Hanya di atas blok putih atau paper.
- `maulanahrp-horizontal-white.svg`: tinta putih. Di atas blok ink atau blue.
- `maulanahrp-horizontal-black.svg`: tinta #0C1A38 (= ink). Untuk cetak satu warna.
- `maulanahrp-badge-color.svg`: badge bulat (logo resmi). Untuk avatar media sosial dan stiker merchandise.

Jangan memutar, memiringkan, atau memberi logo bayangan keras.

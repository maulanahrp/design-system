# Logos

Logo MaulanaHRP yang sama dengan gaya utama. Wordmark sudah berupa outline Montserrat.

- `maulanahrp-horizontal-navy.svg`: tinta navy #1C366B. **Default di Neubrutalism** karena terbaca di atas semua blok terang (paper, sky, cyan, sun, mint).
- `maulanahrp-horizontal-color.svg`: mark bergradasi + teks navy. Hanya di atas blok putih atau paper.
- `maulanahrp-horizontal-white.svg`: tinta putih. Di atas blok ink atau blue.
- `maulanahrp-horizontal-black.svg`: tinta #0C1A38 (= ink). Untuk cetak satu warna.
- `maulanahrp-badge-color.svg`: badge bulat. Untuk avatar media sosial dan stiker merchandise.

Jangan memutar, memiringkan, atau memberi logo bayangan keras.
